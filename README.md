
# InternNova Week 4 Assignment
## Statistics, Data Visualization and Exploratory Data Analysis (EDA)

## Project Overview
This project performs statistical analysis and exploratory data analysis on the Amazon Sale Report dataset using Python.

The assignment covers descriptive statistics, probability, outlier detection, data visualization, data cleaning, correlation analysis, insights, and business recommendations.

## Dataset
- Original dataset: `Amazon Sale Report.csv`
- Cleaned dataset: `Amazon_Sales_Cleaned.csv`
- Original dataset size: 128,975 rows and 24 columns
- Cleaned dataset size: 121,180 rows and 24 columns

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Visual Studio Code

## Tasks Completed
1. Mean, Median and Mode
2. Variance and Standard Deviation
3. Correlation and Probability
4. Outlier Detection using IQR
5. Data Visualization using Matplotlib
6. Data Visualization using Seaborn
7. Data Inspection and Cleaning
8. Correlation Analysis and Insights
9. Business Recommendations

## Key Findings
- Mean sales amount: 648.56
- Median sales amount: 605.00
- Mode sales amount: 399.00
- Standard deviation: 281.21
- Correlation between Amount and Qty: 0.0669
- Number of detected outliers: 3,600
- Highest-selling category: Set
- Total sales amount for Set: INR 39,204,124.03

## Business Recommendations
1. Maintain suitable inventory for top-selling product categories.
2. Consider product prices, discounts, categories and order sizes when planning quantity-based offers.
3. Monitor monthly sales trends and plan marketing activities based on demand.
